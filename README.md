
# ♡ For Hritikaa, With All My Love

*A little corner of the internet, made with love.*

This project is a personal romantic website dedicated to Hritikaa — a collection of heartfelt words, memories, apologies, appreciation and little promises for the future.

## 🌷 What's Inside

- A heartfelt personal apology.
- Little reminders of love, trust and accountability.
- Memories worth keeping.
- A collection of things I adore about her.
- Appreciation for the meals she lovingly made.
- A letter written in Bengali.
- Dreams and hopes for our future.
- A little surprise at the end.
- Our song: *Tere Bin Nahi Lagda Dil Mera.*

## 🎨 Design

- Vintage romantic scrapbook aesthetic.
- Warm cream and muted rose colours.
- Elegant serif typography.
- Responsive layout for mobile and desktop.
- Simple animations and interactive elements.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Google Fonts

## 🌐 Live Website

Hosted for free using GitHub Pages.

## ♡ A Little Note

This website is not about being perfect. It is about expressing love, acknowledging mistakes, appreciating the little things and choosing to become better every day.

**Made with love, especially for Hritikaa.**
